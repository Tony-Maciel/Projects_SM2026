# This project contains many programs that simulate some models in statistical mechanics, such as (in increasing difficulty): 
  ## 1) Ehrenfest urn model (entree). 
  ## 2) Brownian motion (dessert). 
  ## 3) Conserved order parameter Ising model with the enhanced bulk diffusion algorithm (main course).
  
Inside each directory, there are other README.txt files which explain the source codes in more detail.
